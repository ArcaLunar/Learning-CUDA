# NF4 解量化 CUDA 项目说明

## 一、领域知识简介

NF4（4-bit NormalFloat）是 QLoRA 论文中提出的一种量化格式，专门针对神经网络权重服从正态分布的特性进行优化。

与传统的均匀量化（如 INT4）或 FP4 不同，NF4 采用**分位数量化**：

* 将标准正态分布 N(0,1) 的累积分布函数（CDF）等分为 16 个区间
* 每个区间内概率质量相等
* 区间边界值作为量化值
* 这 16 个量化值构成一个查找表
* 查找表以 16 个 FP16 常数存储

### NF4 的优势

对于近似正态分布的数据：

* 分位数量化比均匀量化精度更高
* 分布中心区域分配更多量化级别
* 尾部区域分配较少级别

---

## 二、任务内容

开发一个 CUDA 程序，实现**单核（single kernel）NF4 解量化算子**：

* 输入：压缩后的 4-bit 权重
* 输出：解压为 16-bit 浮点（BF16 或 FP16）
* 要求：在 GPU 上完成解量化

---

## 三、输入文件定义

### 1. 权重数据文件（二进制格式）

```
[header]
num_rows: int64        # 权重矩阵行数
num_cols: int64        # 权重矩阵列数
blocksize: int32       # 块大小（通常为 64 或 128）

[data]
packed_weights: uint8[num_rows * num_cols / 2]
                   # 每字节存两个 4-bit 索引

absmax_q: uint8[num_blocks]
                   # 一级量化缩放因子（每块一个）

absmax2: float16[num_groups]
                   # 二级缩放因子（每组一个）

code2: float16[256]
                   # 二级码表

offset: float32
                   # 量化偏移（通常为 0）
```

---

### 2. 参数文件（文本格式）

```
blocksize = 64              # 必须与数据文件一致
compute_type = "bf16"       # 输出数据类型: bf16 或 fp16
target_gpu = "T4"           # 目标 GPU 型号（影响优化策略）
```

---

## 四、输出文件定义

### 1. 解量化后的权重

* 二进制文件
* 行主序存储
* 类型：`bfloat16` 或 `float16`
* 形状：`[num_rows, num_cols]`

---

### 2. 性能日志

需要输出：

* 核函数执行时间（ms）
* 有效内存带宽（GB/s）
* 相比 bitsandbytes 参考实现的加速比

---

## 五、功能要求

### 1. 功能正确性

必须实现：

* NF4 索引到 FP16 的映射
  （NF4 查找表预定义为 16 个常数，需编码在 Kernel 中）
* 正确实现两级缩放解量化公式
* 输出结果与 bitsandbytes 的 `dequantize_blockwise` 对比：

  * 平均绝对误差（MAE） < `1e-2`

---

### 2. 4-bit 解包与内存访问

必须实现向量化内存访问（Packed Store）：

* 每个线程一次处理两个 4-bit 索引
* 计算两个 BF16 值
* 打包成一个 32-bit `uint32_t`
* 一次性写入全局内存

---

### 3. 边界处理

必须支持：

* 任意形状矩阵（无需对齐到块大小整数倍）
* 最后一行部分块的正确边界控制

---

### 4. 平台适配

* 默认需在英伟达平台上支持
* 每在一款国产平台上支持，额外加 20% 乘算系数
